# 공통 Telegram 발송 규약 (모든 프롬프트가 참조)

- 발송은 항상 `./scripts/telegram_send.sh [--silent] "메시지"` 를 통해서만 한다.
  직접 curl을 호출하지 않는다 — 4096자 청킹과 이스케이프를 스크립트가 대신한다.
- **skip/조용한 실패는 알림을 보내지 않는다.** 로그와 `research/cron_activity.md`에만
  남긴다. 야간 실행이 잦으므로 침묵 규율을 어기면 사용자 수면을 방해한다.
- 평문만 쓴다. `parse_mode`는 쓰지 않는다.
- 실패 시 형식: `❌ <skill> 실패: <reason>`
- 사람의 시뮬레이션 확인이 필요하면 이 형식으로 보낸다:
  ```
  🧪 [MP-NNNN] <한 줄 제목>
  실행: <셸 명령 한 줄>
  확인:
  - <확인 항목>
  결과: 답글 "ok" / "fail: <한 줄>" / "skip"
  ```
- 마지막 단계에서 `research/cron_activity.md`의 오늘 날짜 섹션에 한 줄 추가한다:
  `- HH:MM \`<script>\` · <80자 이내 한국어 한 줄>`
